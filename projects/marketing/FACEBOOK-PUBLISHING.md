# Prompt, review, publish

The Agent page always displays **What would you like to post?** above automatic-drafting controls. Manual assignments work with incomplete brand teaching: missing setup is shown beside the form and retained in the draft's evidence notes. Automatic drafting and live research still require the full knowledge checks. Manual generation never publishes directly.

Choose a brand, destination and brief, then **Create post draft**. Facebook text posts have **Publish or schedule** on the review page, showing the exact destination Page. The owner/administrator must attest that the displayed text and its claims were reviewed. **Approve & publish to Facebook** sends that exact copy; **Approve & schedule on Facebook** sends it to Meta's native scheduler, which runs independently of the app being open. Facebook supports times from 10 minutes to 75 days ahead. The input uses the device timezone and submits an ISO UTC timestamp. Calendar entries use the accepted scheduled date.

This is explicit owner-authorized text-only Page publication. It does not enable unattended automatic publishing, group posting, or publication to other platforms. Global automatic-publishing settings remain unchanged. Only SOCIAL_POST, CAPTION and THREAD content targeting Facebook is eligible. High/blocked risk, incorrect/conflicting facts, prohibited claims and unresolved [VERIFY] markers block publication. The owner's explicit review records factual support and clears media policy only because this path has no media attachments. Approval, the frozen text snapshot, Page and schedule are audited atomically before the provider call.

Claims lock the content row and bind its version plus destination Page. There is one delivery record per content item; duplicate requests cannot send another post. Credentials stay encrypted and only enter server code after an administrator-authorized claim. Network failures, 5xx errors and malformed/ambiguous replies are UNKNOWN: no automatic retry. A definite Meta 4xx error is REJECTED and can be explicitly retried after correcting permissions, at most three attempts with a 30-second cooldown. Success receipts record the provider post ID. If receipt persistence fails, the existing processing record still blocks a duplicate send.

Scheduled means accepted by Facebook's scheduler, not independently verified as published at the future time. Manage, cancel, or check its current status in Facebook. Images, video, Instagram and other networks need their own publishing adapters. Existing Facebook app permissions (`pages_manage_posts`, appropriate Page access and associated read/list scopes) must be granted; expired or insufficient credentials require reconnection.

Apply `supabase/migrations/20261119020000_facebook_live_publication.sql` before the release. It also adds an atomic channel-aware AI save wrapper. Tables have tenant RLS; mutations go through administrator-checked RPCs, while AI saves retain the existing editor and budget checks. Tests use mock providers and local PostgreSQL; no public posts are created during validation.

Official API reference: https://developers.facebook.com/docs/graph-api/reference/page/feed/
